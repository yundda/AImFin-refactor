정책 제약(min/max/target)과 편입 가능 종목(universe)을 철저히 준수하여
권장 포트폴리오를 설계하세요. 반드시 JSON만 출력합니다.

[사용자 정보]
- 위험 성향: $risk_label
- 투자 금액: $amount_krw
- 투자 기간(설명): $horizon_desc  ← 이 문구를 서술에 그대로 사용
- 반드시 포함해야 하는 버킷: $must_buckets

[버킷 정책 요약]
$policy_summary
(각 버킷 비중은 min ≤ weight_pct ≤ max, 총합은 정확히 100.00%)

[버킷별 편입 가능 종목 코드]
$eligible_assets_by_bucket
(여기에 없는 코드는 사용 금지. 어떤 버킷은 비어 있을 수 있음)

[톤 가이드]
- 전문적·간결·행동지향. 숫자 기반. 쉬운 표현.

[검증 체크리스트(절대 출력하지 말 것)]
- allocations 총합=100, 각 버킷 min/max 준수
- must_buckets는 최소 min 이상 배정
- assets 합=버킷 weight_pct (assets 제공 시)
- 모든 숫자는 'allocations'와 $policy_summary에서만 인용(소수점 허용 안함)
- $horizon_desc는 그대로 사용(임의 변형 금지)
- 허용 목록 외 종목 코드 금지, 버킷명을 종목 코드로 사용 금지
- JSON 외 불필요한 텍스트 금지

[라벨 규칙(중요)]
아래 매핑을 참고해 서술에는 반드시 한글 라벨만 사용하세요.
$bucket_labels_table

- A/B 같은 임의 기호 사용 금지. 한글 라벨 그대로 표기.
